Network Discovery
?
Scans the local network for vulnerable TVs — including every device family in the CVE database (Samsung Tizen, LG webOS, Android TV, Roku, Vizio, Hisense, TCL, Chromecast) via their signature ports. Each result shows open ports, the matched CVEs (colored by severity), and status. Use "Check" to verify a device before exploitation, "Exploit" to stage a payload, or "Patch" to execute that family's remediation commands and fix the matched CVEs on the device.
ℹ️ Scan the local network to discover vulnerable TVs and IoT devices.
Exploit Payload Generator
?
Select a target TV from the dropdown (populated from scan results and connected devices) or add a custom IP with the "Custom IP" button, pick a device family, then click Generate to create the payload. Click Exploit to execute the exploit module against the target right now — the activity log reports the module's real outcome (success, failure, timeout or error, with duration).
⚠️ For authorized security testing only. Use only on devices you own or have permission to test.
CVE Monitor & Patch Management
?
Fetches new smart TV CVEs from NVD (runs automatically at every C2 start and on "Update CVEs"). New entries land in the CVE Feed on the right and in CVE_UPDATES.log at the repo root. Use "View Whitepaper" / "View Vulnerability Info" on any feed entry to render it in the Output panel; each press replaces the previous content. Use "Patch" on a scan result or device card to execute that device family's remediation commands against the matched TVs. With an AI key configured, every new CVE gets the full artifact set: exploit module, whitepaper, a pytest test that must pass, a detection-signature proposal and a patch-check proposal.
ℹ️ Monitor known CVEs affecting smart TVs and apply patches to vulnerable devices found on the network.
AI Provider Keys (Auto-Exploit Generation)
?
Keys used to generate a working exploit module for each new CVE automatically. Providers: OpenRouter (Uncensored), Venice AI (Uncensored V 1.2 / Qwen 3.6 Plus Uncensored / GLM 4.7 Flash Heretic), Abliteration.ai (Abliterated Large v2), and a keyless Local Model — a llama.cpp GGUF or Apple MLX server hosted by the C2 machine (enter its endpoint URL; default http://127.0.0.1:8080/v1/chat/completions). Keys can also be supplied via .env (checked first by run_c2.bat) or c2_data/ai_keys.json. Keys are masked after saving.
⚠️ Keys are stored locally in c2_data/ai_keys.json. Never commit this file.
All available providers and their models are listed here. Select one to use for exploit generation.
Exploits Dashboard
?
Lists all generated exploit modules on this C2 with their CVE, TV type, severity, and historical success rate (based on past run results). Use "Generate Exploit" on a CVE in the feed to create one, then refresh here.
ℹ️ Generated exploits stored in data/exploits/generated/.

New CVE Feed
?
Live feed of smart TV CVEs. Refreshed automatically every time the C2 starts and via the "Update CVEs" button on the CVE Monitor tab. New entries are logged to CVE_UPDATES.log in the repository root. Each entry links to its NVD advisory and whitepaper, and has "View Whitepaper" / "View Vulnerability Info" buttons that render into the Output panel. With an AI provider key configured, each new CVE gets a full artifact set: exploit module, whitepaper, a pytest test that must pass, a detection-signature proposal and a patch-check proposal.
